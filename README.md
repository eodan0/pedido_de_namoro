# Um segredo nosso ♡ — site de pedido de namoro

Site estático responsivo feito com HTML, CSS e JavaScript.

## Como testar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Digite a senha `05/06` (também aceita `0506`).

## Como publicar grátis com GitHub Pages
1. Entre em https://github.com e crie uma conta, se precisar.
2. Crie um repositório público chamado `pedido-de-namoro`.
3. Envie os três arquivos (`index.html`, `style.css`, `script.js`) para a raiz do repositório.
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
7. Aguarde a publicação. O GitHub mostrará o endereço do site na mesma tela de Pages.

## Importante sobre a senha
A senha é uma barreira divertida, não uma proteção real: em um site estático, alguém que inspecione o JavaScript pode descobrir a senha. Não coloque informações privadas ou sensíveis no site.

## Personalização
Edite o texto da carta em `index.html`. Cores, fontes e aparência estão em `style.css`.
